# Project notes: your reference collection

Conventions and state of your own report. This file ships as a template: fill it in, or let the coach write down what you decide. The coach verifies the state against the files before relying on it, and updates this file, with your agreement, when a convention changes.

## Conventions

- **Reference folder**: `<path>`. PDF naming, for example `NNN(key)_FirstAuthor_Title_Venue.pdf`, where `NNN` is the reference number and `key` the BibTeX key. Where hand-downloaded PDFs go, and the file that lists papers with no PDF on disk.
- **Numbering**: for example, later batches are appended with the next numbers and earlier numbers never change.
- **Reading standard**: for example, every reference gets one Sonnet-class reader and an Opus-class re-check of its findings; a single read only when you ask for it, listed as an open check.
- **Texts**: page-marked text files, one per key (`===== page N =====`). Page numbers are those of the local PDF.
- **Files of the collection**: bibliography, reference notes, verification table, claims table, reading log.
- Folder quirks worth recording (for example, a synced folder that duplicates files written twice).
