# Project notes: your slide assets

State of your own report. This file ships as a template: fill it in, or let the coach write down what you decide. The coach verifies it against the files before relying on it.

- **Folders**: where the reference PDFs are, where crops go (for example `NNN_key_Label.pdf` and `.png`), and where the contact sheets go.
- **Table**: the slide-assets CSV, its number of rows, how many crops exist, and the date.
- **Triage**: whether the `slide_use` column has been confirmed by you or is still the coach's proposal.
- **Purpose of the page, in your words**: what your supervisor should be able to judge from it.
- **Who builds the page**, and conventions on it (for example, how main questions are numbered).
